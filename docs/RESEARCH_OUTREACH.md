# State of AI Agent Skills 2026 Outreach

Updated: 4 September 2026

Use the report, not the homepage, when the reader needs registry data:

https://www.aipm-registry.com/research/state-of-agent-skills-2026

The report is useful because it has a public method, an hourly refreshed JSON dataset, clear limits, and direct source links. Do not describe it as a study of every Agent Skill on the internet.

## Priority audiences

| Audience | Why it is relevant | Suggested link |
| --- | --- | --- |
| Agent Skill researchers | They can compare registry metadata with larger GitHub datasets | Report and JSON dataset |
| Skill maintainers already listed in AIPM | They can correct metadata, claim a listing, or add missing source details | Their package page and report |
| AI coding newsletters | The report provides a small but reproducible ecosystem snapshot | Report |
| Developer-tool directories | AIPM is a working open-source developer tool with public docs | Skills registry |
| Agent Skill directories | AIPM can exchange format and compatibility findings without copying listings | Compatibility guide and report |

## Research note

Subject: Open registry snapshot for Agent Skills research

Hi [name],

I read your work on [paper, dataset, or repository]. I maintain AIPM, an open registry and package manager for Agent Skills.

I published a reproducible snapshot of the public AIPM registry. It includes package versions, declared tool targets, source links, licenses, integrity values, publisher state, and the method used to collect the data:

https://www.aipm-registry.com/research/state-of-agent-skills-2026

The dataset covers AIPM only, not every Agent Skill online. I thought it may be useful as a small registry-based comparison source. Corrections and format feedback are welcome.

## Before sending

- Personalize the first sentence and mention one real piece of work.
- Link to the exact package, guide, or dataset that helps the reader.
- Ask for review, correction, or use of the data; do not ask for a backlink directly.
- Do not imply endorsement from imported publishers.
- Follow up once after 10 to 14 days, then stop.
