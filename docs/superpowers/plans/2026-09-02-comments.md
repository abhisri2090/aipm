# Comments Implementation Plan

> **For agentic workers:** Implement task-by-task.

**Goal:** Public comment threads on package and prompt detail pages with one-level replies, author edit/delete, and site-admin delete.

**Architecture:** `comments` table + `registerCommentRoutes` in registry-api; shared `CommentsSection` client component on package + prompt detail pages.

**Tech Stack:** Fastify, Postgres, Next.js, existing session + admin session auth.

## Global Constraints

- Public read; login to post/reply
- One reply level only
- Soft delete; site admin can delete any
- Package target key = package name across versions
- Sort: replyCount DESC, then created_at DESC; replies ASC
- Plain text + emoji + autolinked http(s) URLs
- Body 1–2000 chars
