# AIPM SEO keyword map

Last updated: 27 August 2026

## Strategy

AIPM has two audiences. Technical users already know the tool or file they need help with. They search for exact terms such as `AGENTS.md`, `Cursor rules`, `Claude Code skills`, and `mcp.json`. These users are the first priority because AIPM directly solves their reuse and versioning problems.

Non-technical users know that AI can help them, but they may not know words such as MCP or agent skills. Their pages should start with a normal work problem and explain the technical option in simple words. This is the second priority.

Each priority query must have one main page. Supporting pages may link to it, but they should not compete for the same search intent.

## Measurement rules

Check Search Console every week, but make content decisions from a 28-day view. New pages need time to be crawled and tested. Track impressions, clicks, click-through rate, average position, indexed status, and the exact queries shown for each page.

Improve a page when it has impressions but a weak click-through rate, ranks between positions 6 and 20, or receives queries that the answer does not cover. Do not create a second page for the same intent. Update the existing main page instead.

The technical cluster is complete when every priority query has a crawlable, indexable, answer-first page with a clear title, one main heading, internal links, FAQ data, and primary sources where facts depend on a tool's current behavior.
