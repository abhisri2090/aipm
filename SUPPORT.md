# Support

Use the public website and docs first:

- Website: https://www.aipm-registry.com
- Registry status: https://www.aipm-registry.com/status
- FAQ: https://www.aipm-registry.com/faq
- Publishing guide: https://www.aipm-registry.com/publish/guide

## Public Questions And Bugs

Open a GitHub issue for:

- CLI install or command problems
- registry API bugs
- website or documentation issues
- adapter behavior for Cursor, Claude, or future tools
- package validation problems
- feature requests

Please include the command, expected result, actual result, AIPM CLI version,
Node.js version, OS, and any non-sensitive logs.

## Security Or Private Data

Do not put secrets, tokens, customer data, private package contents, or exploit
details in public issues. Follow `SECURITY.md` instead.

## Production Service Operations

The public repository contains deployment scripts, but production credentials,
cloud resources, and incident response are maintainer-operated. Contributors do
not need Azure, Vercel, npm, or GitHub organization access to work on code.
